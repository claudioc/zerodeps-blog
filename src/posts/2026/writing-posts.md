A short tour of what you can use when writing a post.
---

## Headings, lists and links

- **Bold**, _italic_ and `inline code`
- [Links](https://example.com)
- Images: put them in `src/img/` and reference them as `/img/name.webp`

## Code blocks

```js
function greet(name) {
  return `Hello, ${name}!`;
}
```

> Blockquotes work too.
